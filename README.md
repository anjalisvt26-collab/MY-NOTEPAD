# 📝 My Notepad

A simple and user-friendly **Notepad Web Application** built using **HTML, CSS, and JavaScript**.
It allows users to create, edit, and manage notes directly in the browser.

## 🚀 Features

* ➕ Create new notes
* ✏️ Edit existing notes
* 🗑️ Delete notes* 
* 📱 Simple and responsive user interface
* 🎨 Clean and attractive design
* ⚡ Fast and easy to use

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling and responsive design
* **JavaScript** – Application functionality and DOM manipulation

## ▶️ How to Run
Open the project folder.
 Open `index.html` in your browser.

Or, if you are using **VS Code**, open the project and run it using **Live Server**.
